# Plans des lots

Un fichier par lot, écrit par le skill `lot` avant le code et validé par Laurent :
`lot-N.md` (issue, commit de départ, tâches par couche, tableau critère → test → couche,
écrans à capturer, verdict des vérificateurs).

Les captures d'écran du lot vont dans `captures/lot-N/`, nommées
`<ecran>-<etat>-<clair|sombre|mobile>.png`.
